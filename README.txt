PORTFOLIO CÁ NHÂN — HƯỚNG DẪN NHANH

1. Mở file index.html bằng trình duyệt để xem website.
2. Sửa nội dung trong dấu [ngoặc vuông] thành thông tin của bạn.
3. Ảnh đại diện: thay khối .avatar-placeholder trong index.html bằng:
   <img class="avatar-image" src="images/avatar.jpg" alt="Ảnh đại diện của bạn">
   Sau đó thêm CSS:
   .avatar-image { width:100%; height:185px; object-fit:cover; border-radius:12px; }
4. Để đổi kỹ năng, sửa tên và phần trăm width trong các thẻ .skill-item ở index.html.
5. Dự án: sửa data-category="web" hoặc data-category="app" để dùng bộ lọc.
6. Biểu mẫu liên hệ hiện chỉ kiểm tra dữ liệu ở trình duyệt, CHƯA gửi email thật.
7. Thư mục:
   - index.html: cấu trúc nội dung
   - css/style.css: giao diện và responsive
   - js/script.js: menu mobile, giao diện sáng/tối, lọc dự án, kiểm tra form, hiệu ứng xuất hiện
   - images/: đặt ảnh của bạn tại đây

GỢI Ý: tìm các cụm [Tên của bạn], [Mô tả...] trong index.html bằng Ctrl+H để thay nhanh.
